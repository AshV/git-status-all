Command Options

CLI Flags & Options

Unified parameters across PowerShell, Bash, and Windows Batch.

Flag PowerShell Bash / CMD Description
Scan Path -Path <dir> <dir> (arg) Root folder to scan. Defaults to current directory (.).
Dirty Only -Dirty -d, --dirty Hides clean repositories to focus strictly on pending work.
Fetch Remotes -Fetch -f, --fetch Runs git fetch before checking ahead/behind (needs network).
Export File -Export <file> -o, --output <file> Exports scan results to file (format inferred: .csv, .md, .json).
Quick Export -Export -e, --export Instant export to timestamped CSV (e.g. git-status-report-YYYYMMDD.csv).
Version -Version, -v -v, --version Display version number (v2.0.1) and exit.
Workflow Integration

Run globally with an alias

Create a shorthand alias like gsa to inspect any directory on your computer in seconds.

PowerShell ($PROFILE)

Windows

Add to your PowerShell profile to invoke from any directory:

function gsa { & "C:\Tools\git-status-all.ps1" @args }

Bash & Zsh (.bashrc / .zshrc)

macOS / Linux

Add to ~/.bashrc or ~/.zshrc on macOS/Linux:

alias gsa='/usr/local/bin/git-status-all.sh'
